BANEY · Screen Flow de la app móvil

Recorrido pantalla por pantalla de todos los casos de uso del sistema, agrupados por rol. Cada fila es un caso de uso: se lee de izquierda a derecha siguiendo las flechas. Las capturas son reales, tomadas del build actual de la app (Expo, 390×844) con datos de ejemplo.

→ navegación⇢ ramal alternativo o de errorruta en monoespaciado = archivo en src/app/
Generado desde docs/screen-flow/ del repositorio caneyRD/baney-frontend-mobile. Las capturas se regeneran con node docs/screen-flow/capturar.js tras npm run export:web. Las llamadas a la API están simuladas en las capturas; la API real responde en producción.
